# Data-Driven-Domestic-Energy-Optimization-with-ML-Forecasts-Cost--and-Carbon-Aware-Scheduling
End-to-end ML system for domestic energy optimization. Includes data processing, XGBoost/LightGBM forecasting, SHAP explainability, a FastAPI prediction &amp; scheduling API, and a Streamlit dashboard for cost- and carbon-aware appliance recommendations using smart-meter, weather, and property data.
